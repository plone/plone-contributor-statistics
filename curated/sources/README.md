# Sources

The sources that the registers and the curated data cite: `sources.csv` has one row per source, and `excerpts/<id>.md` holds the passages cited from it.

Edited through the capture tool, not by hand: `python -m scripts.tools.capture URL --quote TEXT`.
Never paste whole pages here, only the passages we cite.
See [Capture a source](https://plone.github.io/plone-contributor-statistics/docs/how-to/capture-a-source.html).
