The searchResults method of portal_catalog assumes that if 'show_inactive' is in the "request" object, inactive content should be shown regardless of the value of the parameter.  As a result, it should not be added to the query here.  Though this is a bug that should probably be fixed in CatalogTool, this package should try to retain compatibility with older versions of Plone which have that bug.
