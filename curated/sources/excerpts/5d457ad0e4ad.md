Fix solr sync maintenance command not committing all batches.

Because the maintenance view doesn't commit the ZODB transaction, Solr commits
must not be deferred into a ZODB txn post commit hook in this view, otherwise
they won't get executed.

This was partially addressed in #191, but some conn.commit()'s were missed
(or maybe introduced later).
