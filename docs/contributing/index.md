# Contributing

Corrections and improvements are welcome as pull requests on GitHub.
These pages describe the rules that keep data, method and documentation consistent.

The most important rule for data: every change needs a public record, captured into the source register and cited by its id.
A confirmation by the person in public, such as a comment on the pull request, is a record too, and is captured like any other source.
{doc}`/how-to/capture-a-source`, {doc}`/how-to/add-a-person`, {doc}`/how-to/add-an-affiliation`, {doc}`/how-to/link-old-commits-to-a-person` and {doc}`/how-to/add-curated-community-data` show how to send one.
