# Contributing

Corrections and improvements are welcome as pull requests on GitHub.
These pages describe the rules that keep data, method and documentation consistent.

The most important rule for data: every change needs a public record, linked in its source, or a confirmation by the person in the pull request.
{doc}`/how-to/correct-an-organisation-mapping`, {doc}`/how-to/link-old-commits-to-a-person` and {doc}`/how-to/add-curated-community-data` show how to send one.
